## 📥 匯入說明

### 方法：拖曳匯入

1. 在 Notion 左側欄點擊 **「＋ 新頁面」**
2. 選擇 **「匯入」** → **「Markdown」**
3. 拖曳 `docs/` 目錄下的 **7 個 `.md` 文件**

### 或：複製貼上

1. 執行命令讀取文件：
```bash
cat ~/.openclaw/workspace/codes/TradeMaster_v2/docs/TECHNICAL_SPEC.md
```

2. 複製內容貼上到 Notion 頁面
